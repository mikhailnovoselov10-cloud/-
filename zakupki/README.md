# Журнал закупок

Приложение для учёта денег клиентов в совместных закупках с фабрик.

- **Клиенты** — ник (можно менять), имя, телефон, где общаетесь, заметки; у клиента виден список его закупок.
Две вкладки: **Закупки** и **Клиенты**.

- **Закупки** — название, фабрика, дата, статус (сбор → заказано → в пути → прибыла → закрыта) и процент предоплаты. Внутри — список «кто записан»: сколько вещей, внесено, долг и статус (нет предоплаты / предоплата не вся / предоплата внесена / оплачено полностью), с фильтрами.
- **Клиент в закупке** — клиента добавляют в закупку и вешают на него сколько угодно вещей (артикул, размер/цвет, количество, цена). Предоплата и оплаты считаются отдельно по каждой закупке: видно, сколько вещей на нём, сколько внесено и сколько осталось доплатить.
- **Оплаты** — предоплата, доплата, возврат; к каждой можно прикрепить фото чека или скриншот перевода.
- Сводка «кто сколько должен», копирование списка доплат по закупке и текста-напоминания клиенту.
- Резервная копия всех данных вместе с фото в один файл и восстановление из него.

## Файлы

- `app.html` — исходник страницы (публикуется как Claude Artifact; там данные и фото хранятся в облаке и синхронизируются между устройствами).
- `index.html` — та же страница как обычный HTML-файл: открывается в любом браузере, данные хранятся в этом браузере (IndexedDB). Делайте резервные копии через меню «⋮».

`index.html` собирается из `app.html`: первые 10 строк `index.html` (обёртка `<head>`) + `app.html` + закрывающие теги.
