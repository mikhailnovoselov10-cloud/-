# Медиа для игры «9 уровней»

Положите сюда файл с нужным именем, и бот сам отправит его вместе с текстом этого шага.
Если файла нет, бот просто отправит текст.

Форматы: видео `.mp4`, гифка `.gif`, картинка `.jpg` / `.png` / `.webp`.

| Имя файла (без расширения) | Шаг игры |
|---|---|
| `intro` | Приветствие (/start) |
| `identify` | «Первый этап — идентификация», просьба ввести дату |
| `level1` | Уровень 1 — Точка А, выбор запроса |
| `route` | «Маршрут построен», запрос сохранён |
| `level2` | Уровень 2 — Тень |
| `level3` | Уровень 3 — линия мамы |
| `level4` | Уровень 4 — линия папы |
| `level5` | Уровень 5 — Точка Б, код потенциала |
| `level5_more` | Уровень 5 — расшифровка потенциала |
| `level5_voice` | Голосовое к уровню 5: `.ogg` (как голосовое) или `.mp3` (как аудио) |
| `level6` | Уровень 6 — «Начинаем анализ…» |
| `level6_result` | Уровень 6 — итог и главный барьер |
| `level7` | Уровень 7 — Прорыв года |
| `level8` | Уровень 8 — ответ на запрос |
| `level9` | Уровень 9 — финал, поздравление |
| `level9_offer` | Уровень 9 — подарок и предложения |

### Разборы тем

| Имя файла | Шаг |
|---|---|
| `topic_money`, `topic_love`, `topic_purpose`, `topic_career`, `topic_anxiety`, `topic_energy`, `topic_scale` | Первый экран разбора темы (обложка темы) |
| `topic2` … `topic5` | Шаги разбора: сила, сценарий, точка роста, прогноз на год (общие для всех тем) |

### Прогрев после игры и напоминания

| Имя файла | Шаг |
|---|---|
| `drip1` … `drip7` | Сообщения прогревающей цепочки (1 — через 45 минут после игры, 7 — через ~44 часа) |
| `card1` … `card9` | Картинка карты дня (Ясность, Сила, Изобилие, Действие, Любовь, Интуиция, Смелость, Отдых, Благодарность) |
| `door1` … `door6` | Картинка к расшифровке выбранной двери |

### Видео-кружки (отзывы, обращение автора)

Перед любым шагом можно отправить до 7 кружков: `<шаг>_circle.mp4`, `<шаг>_circle1.mp4` … `<шаг>_circle6.mp4`.
Например, `drip2_circle1.mp4` … `drip2_circle6.mp4` — шесть кружков-отзывов перед вторым сообщением прогрева.
Кружок — квадратное видео до 1 минуты (Telegram сам сделает его круглым).

Пример: `media/level2.mp4`, `media/level5_voice.ogg`.

Если текст шага длиннее 1000 символов, медиа уходит отдельным сообщением прямо перед текстом:
это ограничение Telegram на длину подписи.
После добавления файлов перезапустите бота: `pm2 restart bot`.
