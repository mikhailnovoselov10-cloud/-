# Бот «Разбор по дате рождения»

Telegram-бот с нумерологическими разборами. Node.js 22.13+, grammY, встроенная `node:sqlite`.

## Запуск

```bash
npm install
cp .env.example .env   # заполните BOT_TOKEN, CRYPTOPAY_TOKEN, ADMIN_IDS
npm start
```

## Настройка оплаты

### Telegram Stars ⭐
Ничего подключать не нужно: Stars работают у любого бота. Бот выставляет счёт в валюте
`XTR` без платёжного провайдера. Звёзды копятся в @BotFather → ваш бот → **Balance**
(там же вывод через Fragment).

### CryptoBot 💎
1. Откройте [@CryptoBot](https://t.me/CryptoBot) → **Crypto Pay** → **Create App**.
2. Скопируйте токен API в `.env`: `CRYPTOPAY_TOKEN=...`.
3. Для теста без реальных денег используйте [@CryptoTestnetBot](https://t.me/CryptoTestnetBot)
   и `CRYPTOPAY_TESTNET=true` (токен testnet-приложения).
4. Webhook не нужен: бот сам проверяет счета каждые 15 секунд, а у пользователя есть кнопка
   «Я оплатил — проверить».

Счёт выставляется в USD (`fiat`), пользователь платит любой монетой из `CRYPTOPAY_ASSETS`.
Если `CRYPTOPAY_TOKEN` пустой, кнопка крипты просто не показывается.

## Если провайдер блокирует Telegram
Укажите SOCKS5-прокси в `.env`, можно прямо в том виде, как его выдал продавец:
```
PROXY_URL=ip:порт:логин:пароль
```
Через прокси пойдут и запросы к Telegram, и запросы к CryptoBot.

## Защита от двойной выдачи

- Каждый платёж записывается один раз: `UNIQUE(provider, external_id)`
  (`telegram_payment_charge_id` для Stars, `invoice_id` для CryptoBot).
- Заказ переходит `pending → paid` условным `UPDATE ... WHERE status='pending'` в той же транзакции,
  что и выдача прав. Один заказ оплачивается и выдаётся ровно один раз.
- Повторный платёж за уже оплаченный заказ товар не выдаёт. Stars возвращаются автоматически
  (`refundStarPayment`), о повторной оплате криптой приходит уведомление админу.
- Купленное хранится в `entitlements` и всегда доступно в «Мои разборы».

## Прочее
- Метки трафика: `https://t.me/ВашБот?start=метка` (латиница, цифры, `_`, `-`).
- `/stats` для ID из `ADMIN_IDS`: пользователи, выручка, продажи, конверсия по меткам.
- Ежедневный прогноз уходит в `DAILY_HOUR` по `TIMEZONE` (по умолчанию 9:00 МСК).
