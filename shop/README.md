# Сайт совместных закупок

Каталоги фабрик с фото, запись клиентов под товаром, админка для настройки всего.
Node.js 22.13+, Express, встроенная `node:sqlite`, `sharp` для сжатия фото.

## Запуск

```bash
cd shop
npm install
cp .env.example .env   # обязательно задайте ADMIN_PASSWORD
npm start
```

Сайт: `http://localhost:3000`, админка: `http://localhost:3000/admin`.

## Как работать

1. **Админка → Новая закупка.** Название, условия, дата стопа, орг. сбор в % (клиенты видят цену уже с ним).
   Статусы: *черновик* (видите только вы), *открыта* (идёт запись), *стоп* (видна, запись закрыта), *архив*.
2. **Загрузить каталог.** Выберите сразу все фото от фабрики:
   - «каждое фото — отдельный товар» или «все фото — один товар» (ракурсы одной модели);
   - галочка «артикул = имя файла», если фабрика называет файлы артикулами;
   - можно сразу задать всем цену, размеры, цвета.
3. **Редактирование товаров.** В списке — быстрые поля (название, артикул, цена, размеры, цвета).
   «Все настройки и фото» — описание, лимит штук, свои параметры (например `Рост: 158, 164`), фото
   (добавить, удалить, сделать главным), скрытие.
   Отметьте несколько товаров галочками → задайте цену/размеры/цвета всем сразу, объедините в один товар или удалите.
4. **Клиенты** открывают закупку, жмут «Записаться», выбирают параметры, количество, пишут имя и контакт.
   Запись сразу появляется в списке под фото (контакт видите только вы). Клиент может отменить свою запись,
   пока закупка открыта, и видит всё, что заказал, на странице «Мои записи».
5. **Записи** (кнопка на странице закупки):
   - *Заказ для фабрики* — сколько штук каждой модели в каждом размере/цвете, сумма;
   - *По клиентам* — кто сколько должен с учётом орг. сбора и сколько оплачено;
   - статусы записей (подтверждена, оплачена, выдана…), правка, удаление, ручное добавление;
   - выгрузка в CSV (открывается в Excel).
6. **Копия закупки** — те же товары и фото без записей, удобно для повторного сбора.

## Уведомления в Telegram
Укажите `TG_BOT_TOKEN` (любой ваш бот) и `TG_CHAT_ID` — о каждой новой записи придёт сообщение.

## Данные
База — `shop.sqlite`, фото — папка `uploads/`. Для резервной копии сохраняйте обе.
