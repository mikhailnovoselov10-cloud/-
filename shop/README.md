# Сайт совместных закупок

Каталоги фабрик с фото, запись клиентов под товаром, админка для настройки всего.
Node.js 22.13+, Express, встроенная `node:sqlite`, `sharp` для сжатия фото.

## Запуск

```bash
cd shop
npm install
cp .env.example .env   # обязательно задайте ADMIN_PASSWORD
npm start
```

Сайт: `http://localhost:3000`, админка: `http://localhost:3000/admin`.

## Админка

Слева — меню:
- **Главная** — сводка: открытые закупки, новые (необработанные) записи, записи за сутки и неделю, последние записи.
- **Закупки** — все закупки с фильтром по статусу. Под пунктом — список закупок; выберите закупку, и появятся её разделы:
  - **Товары** — загрузка каталога перетаскиванием фото (можно сотни сразу, с прогрессом), карточки товаров,
    поиск, перетаскивание для порядка, галочки → изменить цену/размеры/цвета всем сразу, скрыть, объединить, удалить;
  - **Записи** — фильтр по статусу и поиск, статус записи меняется прямо в таблице;
  - **Заказ фабрике** — сколько штук каждой модели в каждом размере/цвете и сумма, выгрузка в Excel;
  - **Оплаты клиентов** — кто сколько должен, кнопка «Оплатил всё»;
  - **Настройки** — название, описание, дата стопа, орг. сбор, реквизиты для оплаты, копия, удаление.
  Статус закупки (Черновик / Идёт запись / Стоп / Архив) переключается одним нажатием вверху страницы закупки или в списке.
- **Все записи** — записи из всех закупок с фильтрами.
- **Клиенты** — все клиенты с суммами и долгами, карточка клиента со всеми его записями.
- **Настройки сайта** — название, приветствие на главной, контакт, валюта, уведомления в Telegram.

На телефоне меню открывается кнопкой ☰.

## Сайт для клиентов

- Главная — открытые закупки с обложками и сроком стопа.
- Закупка — каталог карточками (на телефоне по две в ряд), поиск, фильтр по размеру, сортировка по цене.
  Под каждой карточкой видно, кто уже записался.
- Товар — все фото (листаются пальцем), размеры и цвета кнопками, количество, имя и контакт,
  кнопка «Записаться» и список записавшихся. Стрелки к предыдущей/следующей модели.
- «Мои записи» — всё, что клиент заказал, суммы, статусы, реквизиты для оплаты. Имя и телефон запоминаются.

## Уведомления в Telegram
Админка → Настройки сайта: токен бота и ваш chat id. Кнопка «Сохранить и отправить тест» проверит, что всё работает.

## Данные
База — `shop.sqlite`, фото — папка `uploads/`. Для резервной копии сохраняйте обе.
